每个“材质 × 行为”走一遍这条线Every material × behavior runs this loop

测真实物体，在 Newton 里拟合参数，再用没参与拟合的试次检查。通过的成为 SimReady 参数；怎么调都对不上的，整理成可复现的缺口报告交给 Newton。Measure real objects, fit parameters in Newton, then check them against trials the fit never saw. What passes becomes SimReady parameters. What no tuning can fix becomes a reproducible gap report for the Newton team.

  • 代码（harness）Code (harness)计算并执行规则，Agent 绕不过。Computes and enforces the rules; agents can’t get around it.

  • AgentAgents各管一类判断，彼此经代码交接；看不到留出数据。Each owns one kind of judgment and hands off through code. None sees held-out data.

  • 人People只做采集，设定预算和门槛。Only collect data and set budgets and gates.

①②①②

数据门、测量Data gate and measurement

代码CodeAgentAgents
  • 自己采的动捕数据逐试次质检，不合格的剔除并记录原因。Every motion-capture trial we record goes through a quality gate. Rejected trials are logged with the reason.
  • 噪声分三层：静止时的跟踪抖动、同一初始状态下各次之间的差异、总离散。Noise is split into three layers: tracking jitter at rest, spread between repeats from the same initial state, and total spread.
  • 仿真和真实用同一套函数算关键量，比如弹跳高度、起滑角、摆动衰减。Sim and real data go through the same functions for key quantities such as bounce height, slip-onset angle and swing decay.
  • 新行为的关键量由定义 Agent 起草，过了准入测试才启用。For a new behavior, a definition agent drafts the key quantities; they are enabled only after passing admission tests.
③③

参数初估Initial parameter estimate

AgentAgents代码Code
  • Solver Agent 查知识库、材质库和文献，给出每个参数的中心值和范围，标注来源和出处。The Solver Agent searches the knowledge base, material library and literature, then proposes a central value and a range for each parameter, with sources.
  • 库里没有的材质做类比。Materials that are not in the library are estimated by analogy.
  • 初估范围经代码校验后才生效。The range takes effect only after a code check.
  • 同一个 Solver Agent 会话接着负责调参和解释残差。The same Solver Agent session goes on to tune the parameters and explain the residuals.
④④

精细调整（Newton 调参循环）Fine-tuning in the Newton loop

AgentAgents代码Code
  • Solver Agent 选候选参数和步长，每一步附一个可检验的预测。The Solver Agent picks candidate parameters and step sizes, each with a prediction the code can check.
  • 代码在初估范围内跑 Newton 仿真并打分，只用训练试次；Agent 看不到留出数据。Code runs Newton within the initial range and scores the result on training trials only. Agents never see held-out data.
  • 收敛或预算用完就停，进入 ⑤。It stops on convergence or when the budget runs out, then moves to ⑤.
⑤⑥⑤⑥

效果诊断、原因诊断Result and root-cause checks

代码CodeAgentAgents
  • ⑤ 只用留出试次，看偏差是否低于阈值。⑤ On held-out trials only, check whether the bias is below the threshold.
  • 仿真误差² = 模型偏差² + σ²。看模型偏差的 90% 置信区间：整段低于阈值算通过，整段高于算不通过，跨在线上算“未定”。sim error² = model bias² + σ². We judge the 90% confidence interval of the model bias: entirely below the threshold passes, entirely above fails, and straddling it is undetermined.
  • ⑥ 不通过就看收敛、残差模式和可辨识性：参数偏差回到 ④ 重新调参，模型缺口直接进结论，数据约束不住参数就转到 ⑦。⑥ On a fail, look at convergence, residual patterns and identifiability. A parameter bias goes back to ④ for re-tuning, a model gap goes straight to a verdict, and parameters the data can’t constrain go to ⑦.
  • 残差由 Solver Agent 解释，审查 Agent 复核，有分歧时做判别实验。The Solver Agent explains residuals, a reviewer agent double-checks, and disagreements are settled by a discriminating experiment.
⑦⑦

采集分诊 → 执行采集Collection triage → collection

代码CodeAgentAgents人People
  • ⑦ 把初估范围代入仿真：关键量的变化不超过精度，算“对任务无影响”；超过就要补数据。⑦ Push the initial range through the simulation. If key quantities move less than the required precision, the parameter has no effect on the task; otherwise we need data.
  • 采集规划 Agent 起草任务卡：标准实验、执行方式、物料清单。A collection-planning agent drafts a task card: standard experiment, execution method, materials.
  • 预算上限内按价值排序、合并去重后自动派发；机械臂优先，人只做机械臂做不了的。数据回流到 ①。Within the budget cap, cards are ranked by value, merged, deduplicated and dispatched automatically. Robot arms run what they can and people do the rest. Data flows back to ①.
  • 要多重复、多条件：单个条件重复 5 次，σ 的 90% 区间上下限相差约 7.6 倍；3 个条件各 10 次能缩到约 1.7 倍。Repeats and conditions both matter: with 5 repeats of one condition the 90% interval for σ spans about 7.6×; 3 conditions × 10 repeats narrow it to about 1.7×.
⑧⑨⑧⑨

结论判定、准入Verdict and admission

代码Code
  • ⑧ 代码给出结论并记录判定路径：已校准、对任务无影响、需采集、仿真能力缺口、感知失败五种之一，判不出来给“未定”。⑧ Code issues one of five verdicts and records how it got there: calibrated, no effect on the task, needs data, simulation capability gap or perception failure. When the evidence can’t decide, the verdict is undetermined.
  • ⑨ 通过的自动准入，写入知识库；下次命中先复核，失败自动降级。⑨ Results that pass are admitted automatically and written to the knowledge base. Every later hit is re-checked first and demoted automatically if it fails.
  • 每个“材质 × 行为”出一份结构固定的报告：结论、参数、verification、validation、诊断，有缺口时附缺口报告。Each material × behavior gets a report with a fixed structure: verdict, parameters, verification, validation and diagnosis, plus a gap report when there is one.
