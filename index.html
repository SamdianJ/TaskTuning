Why the cable model changed

STAGE A

Fit material response

Optimizing EI and damping reduced error, but opposite static orientations traded off and dynamic maximum error remained above the limit.

STAGE B

Test the fixed boundary

A shared clamp-angle correction helped the joint fit. With static values conditionally frozen, viscous damping still traded oscillation amplitude against period.

STAGE C

Add relaxation

An SLS branch added transient rigidity and a relaxation time. No-plug dynamics improved, while attachment uncertainty and loaded numerics remained unresolved.

02 / Plug calibration

Real forces, explained with CAE evidence

A force sensor measures the combined insertion load. Ansys Motion deformation and contact evidence help distinguish the upper latch from the metal electrical contacts. This distinction exposed a missing load contribution that latch stiffness, damping or friction alone could not reliably absorb.

MEASURE

Five real robot repeats

Piper insertion recordings provide axial and lateral force references. All five repeats are scored separately with fixed comparison windows and a shared simulation clock.

EXPLAIN

Separate the load sources

The CAE metal-contact channel has an axial peak of about 5.61 N and excludes the upper latch load. It informs a component of the model; the measured robot total peaks at 11.03–11.59 N.

CALIBRATE

Apply the load in dynamics

A two-parameter, insertion-depth-dependent equivalent load is fitted to real force evidence and applied inside Newton / MuJoCo-Warp. Plug motion, latch angle and contact forces respond to it.

Inspect force components, latch recovery and numerical qualification

The equivalent load follows F(s) = k × clip(s − s₀, 0, L), with k = 1383.238695 N/m, s₀ = 2.98159284 mm and fixed L = 10 mm. Depth is read from the actual plug pose at every substep. This is an effective axial model; its residual load cannot be uniquely attributed to metal elasticity.

In the latest candidate, the release drop comes from changing latch contact while the equivalent load continues to rise. This describes the candidate's internal mechanism, not an independently measured decomposition of the real release.

Observation criteria passed; qualification remains open. All five Piper repeats were used for development, with no independent holdout. The timestep feature change is 0.028135, above the existing 0.015 budget. Different speeds, withdrawal, pull-out locking and complete wrench behavior remain unvalidated for this candidate. The latest local force model has not been integrated into the full robot replay.
